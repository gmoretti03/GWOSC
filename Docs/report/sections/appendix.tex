\section{Reproducibility and origin of the numbers}\label{app:code}

The project is a pipeline of notebooks in \texttt{Code\_General/}, run in order with the Jupyter kernel \texttt{cern} (environment in \texttt{environment.yml}); every random number is generated with a fixed seed and long steps cache their output.
\path{download_data.py} downloads the eight raw chunks (about 0.5\,GB in float32; not tracked); \path{gwosc_tools.py} holds the shared functions (whitening, analytic waveforms, injection, template bank, statistics).
Run times on a 10-core laptop: notebook 01 $\approx$1\,min, 02 $\approx$1\,min, 03 $\approx$10--15\,min (most of it the systematic variants), 04 $\approx$20\,min, 05 $\approx$30--40\,min with training from scratch (a few minutes with the saved models).
